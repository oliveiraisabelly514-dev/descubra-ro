# Descubra RO — Guia Turístico de Rondônia

## Sobre o projeto

O **Descubra RO** é um projeto acadêmico desenvolvido na disciplina de **Ergonomia de Sistemas Computacionais e IHC**, com a proposta de apresentar um guia turístico digital que valorize os destinos, a cultura, a gastronomia e as belezas naturais de Rondônia.

O objetivo é oferecer uma experiência intuitiva, acessível e agradável, permitindo que moradores e visitantes descubram lugares para conhecer e explorar pelo estado.

## Objetivo

Desenvolver uma plataforma digital que facilite a descoberta de pontos turísticos de Rondônia, reunindo informações sobre destinos, categorias de interesse e experiências turísticas em um só lugar.

## Status do projeto

Em desenvolvimento.
